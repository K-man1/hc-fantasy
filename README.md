I'm building a Fantasy Football, but for Hack Club. Honestly, I've never done anything like this, so what is currently submitted is just a counter for the number of messages in #hc-fantasy since October 4th, exactly 1 week ago. The idea is you will be able to "draft" channels and one way a channel can get points is by the number of messages sent.
